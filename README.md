# linux-kernel-labs

Hands-on labs for learning **Linux kernel modules and driver basics**.

The goal of this repository is to build intuition for:

- how kernel modules are built and loaded
- basic driver-style patterns
- logging and debugging in kernel space
- simple interfaces (proc, sysfs, char device, etc.)

Each lab is small and focused, with both **code** and **notes** under `docs/`.
